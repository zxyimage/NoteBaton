# NoteBaton Support

NoteBaton is a local-first notes app for iPhone, Mac, and the web. This page covers the official App and service at notebaton.org.

## Install on Mac

1. [Download NoteBaton 1.0.0 for macOS](https://notebaton.org/downloads/NoteBaton-macOS-1.0.0.dmg). Requires macOS 14 or later; supports Apple silicon and Intel Macs. The app is Developer ID signed and Apple-notarized.
2. Open the downloaded DMG, then drag NoteBaton into the Applications folder shown on the right.
3. Open NoteBaton from Applications. You can then eject the NoteBaton disk image in Finder.

For an update, quit NoteBaton from its menu bar menu before replacing the app in Applications. Keep your existing app data.

## Before contacting support

1. Check that every paired device uses the latest available version.
2. Confirm that paired native devices are online together. Web editing requires the paired iPhone app in the foreground or the Mac app running.
3. If a pairing has expired or was revoked, remove it and generate a new pairing link.
4. Keep an independent backup of important notes. Device sync is not a backup service.
