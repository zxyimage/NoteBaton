# 开源文件检查

检查日期：2026-09-27。范围为本次准备首次提交的源码、配置、文档、生成资源、图标及 Git 提交身份。正式 App 和原开发历史已由维护者另行备份，当前本地 Git 仓库没有历史提交。

## 本次清理

- 移除 Xcode 工程 Debug / Release 中固定的 Apple 开发者 Team ID。公开签名配置只保留空团队和示例 Bundle ID，本地签名模板受 Git 忽略规则保护。
- 清空网站配置中的发布者姓名及联系邮箱，重新生成网站政策、支持页和 App 离线政策。开源副本显示草稿提示；线上政策和已发布 App 不受影响。
- 移除签名 DMG、旧 ZIP、安装包校验文件、DMG 打包脚本及其依赖说明。下载入口改为外部已发布地址，保留客户端源码编译与测试。
- 移除 App Store 上架资料和包含维护者基础设施信息的部署记录，清理文档中不随源码提供的本机测试产物链接。
- 从 11 张 App 图标中移除 EXIF/XMP 等附加元数据，压缩像素数据保持完全相同。
- 本仓库的后续 Git 提交使用公开 GitHub 用户名与 GitHub noreply 邮箱；不改动其他仓库的 Git 配置。
- 扩充忽略规则和 CI 检查，拦截签名材料、固定开发者身份、发布者配置和 App 发布产物。被强制加入 Git 的忽略文件也会被检测。

## 保留内容

- 公开项目地址和官网域名：属于产品入口，不包含账号凭证。
- `LICENSE` 及第三方许可中的署名：属于软件许可信息。
- 通用签名类型、空白配置与测试数据：用于本地开发和回归测试，未发现实际签名密钥、令牌或真实笔记。
- 官网与政策源码模板：用于源码预览；自部署笔记服务不包含这些页面，也不要求填写发布者信息。

该结果是针对当前文件快照的人工与规则检查，不是完整安全审计，也不保证未来修改不会引入敏感内容。每次提交前继续运行：
